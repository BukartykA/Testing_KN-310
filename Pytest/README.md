# Звіт до роботи
## Тема: Тестування з бібліотекою pytest
## Мета роботи: Ознайомитися з можливостями сторонньої бібліотеки `pytest`, навчитися створювати тестові функції, використовувати перевірки через `assert` та `pytest.raises`, застосовувати параметризацію (`@pytest.mark.parametrize`), створювати та перевикористовувати фікстури (`@pytest.fixture` з різними `scope` у `conftest.py`), групувати тести за допомогою власних маркерів та аналізувати вивід помилок.

---

# або через Poetry:
