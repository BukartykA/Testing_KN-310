# Звіт до лабораторної роботи №1
**Тема:** Тестування програмного забезпечення за допомогою unittest та pytest
**Мета роботи:** Ознайомитися з основами тестування програмного забезпечення, навчитися писати юніт-тести та налаштовувати тестове середовище.

## Виконання роботи

1. **Налаштування конфігурацій:**
   Створено файл `pyproject.toml` з налаштуваннями менеджерів залежностей та інструментів тестування pytest і coverage.

2. **Реалізація функцій та юніт-тестів:**
   У файлі `test_app.py` реалізовано функцію `count_vowels(text)`, яка рахує кількість голосних літер у рядку. 
   
   Для функції написано клас тестів `TestVowels` на основі `unittest.TestCase`, що включає 4 тести:
   - `test_vowels_basic` — перевірка звичайного англійського рядка;
   - `test_vowels_empty` — перевірка порожнього рядка;
   - `test_vowels_ukrainian` — перевірка рядка з українськими літерами;
   - `test_vowels_numbers` — перевірка рядка з цифрами.
